GIRLFRIEND BIRTHDAY WEBSITE — ADD HER PHOTO

Folder contents:
  index.html
  girlfriend.jpg       <-- add the girlfriend photo you want to show
  birthday-song.mp3    <-- add your music (optional if using Choose Song)

To put her photo on the actual shared website:
1. Choose the picture you want.
2. Rename it exactly girlfriend.jpg.
3. Put it in the same folder as index.html.
4. Upload BOTH index.html and girlfriend.jpg when publishing the website.
   Upload birthday-song.mp3 too if you want the music available on every device.

The “PREVIEW / CHOOSE HER PHOTO” control lets you preview an image locally in the current browser. That preview does NOT upload the photo to the website or make it visible on your girlfriend's phone. For the shared link, the actual girlfriend.jpg file must be beside index.html and uploaded to the hosting service.

Music autoplay:
Phones may block autoplay with sound until a tap. If necessary, tap Play. You can choose an audio file from the page using CHOOSE SONG FILE.
